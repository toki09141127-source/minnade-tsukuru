# 利用規約の公開準備

Status: USER APPROVAL REQUIRED。2026-10-21。公開文面の確定・法律上の保証ではない。既存LEGAL_RIGHTS_RISK_REGISTER.md、TERMS_PRIVACY_REQUIREMENTS.mdを前提とする。

## 100人公開前に決定する事項

- 運営者名、連絡先、適用日、対象年齢、未成年の同意/保護、相談窓口を実在する運用に合わせる。
- 投稿者の権利とサービスへの許諾（表示・保存・配信・バックアップ・共同編集）を限定列挙。共同作品全体を単独投稿者の所有とみなさない。
- core/supporter/creatorの役割、参加同意、core退出制限、期限公開、final無しの場合に制作ログも公開される条件をUIと一致させる。
- 共同制作の改変・翻案・氏名表示・途中退出・商用利用・外部転載について、誰の合意で何が可能になるかを具体化する。現行画面/規約の禁止範囲と整合させる。
- 無断転載/盗作/二次創作、肖像・商標・名誉に関する禁止と申告手順を用意。権利者申告→暫定非表示→当事者連絡→異議→判断の担当を決める。
- 退会しても残る作品/投稿/名義、例外的削除、保管義務・バックアップからの反映時期を確定。技術上できない即時完全削除を約束しない。
- 利用停止/BAN/異議申立て、重大事故時の公開停止、免責/責任範囲、規約変更と再同意を専門家へ確認する。

## AI方針候補

「ユーザー作品を、本人の明確な同意なく生成AIの学習目的に利用しない」を維持する。推論のためのAPI送信は別の目的・別の同意として説明する。AI禁止ルームは送信しない。provider未選定のまま保持ゼロ/学習ゼロを断定しない。AI機能自体は今回実装/有効化していない。
